## Tablas de la base de datos

El modelo de negocio utiliza cuatro tablas: `Tenants`, `Usuarios`, `Categorias` y `Solicitudes`, tal como indica el enunciado. Las tablas `__EFMigrationsHistory` y `__EFMigrationsLock` son tablas técnicas creadas automáticamente por Entity Framework Core para controlar las migraciones; no representan entidades adicionales del dominio.
